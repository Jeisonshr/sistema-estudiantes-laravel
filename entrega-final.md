## Sistema de gestión de estudiantes

### 1. Información general

- **Proyecto:** Sistema de gestión de estudiantes.
- **Framework:** Laravel 10.
- **Lenguaje de programación:** PHP.
- **Base de datos:** MySQL.
- **Repositorio:** https://github.com/Jeisonshr/sistema-estudiantes-laravel

### 3. Funcionalidades implementadas

El sistema permite:

- Registrar nuevos estudiantes.
- Consultar y visualizar los estudiantes registrados.
- Editar la información de los estudiantes.
- Eliminar registros mediante una confirmación.
- Buscar estudiantes por diferentes datos.
- Validar los campos de los formularios.
- Iniciar y cerrar sesión mediante un usuario operador.
- Restringir el acceso a las funciones internas del sistema.

### 4. Archivos de documentación

El repositorio incluye los siguientes documentos:

- `README.md`: contiene la información general y los pasos para instalar y ejecutar el proyecto.
- `registro-pruebas.md`: presenta los casos de prueba, los resultados observados y el estado de cada prueba.

### 5. Estado de las pruebas

Se realizaron pruebas de algunas de las funcionalidades principales, como la validación de edad mínima, la confirmación de eliminación y la protección de las rutas mediante el inicio de sesión.

### 6. Dificultad encontrada y solución

Una de las principales dificultades fue integrar correctamente Laravel con la base de datos MySQL y configurar el funcionamiento de las diferentes partes del sistema.

Para solucionarlo, se revisó la configuración del proyecto, la conexión con la base de datos y la organización de las rutas y controladores, realizando pruebas para comprobar su funcionamiento.
